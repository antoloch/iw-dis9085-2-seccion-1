# Clase 7 — s12

**Lunes 09-11**

Revisamos un ejemplo de un sitio interactivo logrado sólo con CSS (ver archivo `index.html` `style.css` y carpeta assets). Además, vimos las importancia de diseñar con Auto Layout en Figma y repasamos cómo sacar los códigos CSS en el Dev Mode de manera correcta.

**Sí sacar de Dev Mode:**
* Colores (hex)
* Tipografía (familia, peso, tamaño, interlineado)
* Radio de bordes
* Gap y padding de los frames con **Auto Layout**
* Alineación (justify-content y align-items)

**No sacar de Dev Mode:**
* position: absolute
* Anchos y altos fijos de cada caja
* Márgenes con decimales para «empujar» elementos
* Valores de frames armados sin Auto Layout

Otro método es seleccionar elemento > clic botón derecho > Copiar/Pegar como > Copiar como código > CSS. 
Usar con criterio y no copiar `position: absolute;` y dejar cambiar el width del contenedor principal por `width: 100%;`

También podemos usar Agente (Chat IA) integrado en Figma. Seleccionar elemento y escribir el siguiente prompt:
````markdown
Crea el código sólo con HTML/CSS sin JS. Dejar el width del contenedor principal en 100% para que sea responsive
````

Algunos plugins:
* Figma to Code (Ferrari)
* Convert Figma Design to HTML/CSS
