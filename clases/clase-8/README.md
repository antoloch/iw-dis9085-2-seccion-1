## Exámen final (lunes 23 de noviembre):

Cada estudiante diseña, programa y publica un sitio web real para uno de estos dos casos:
* Su portafolio personal, con trabajos propios de la carrera o de fuera de ella.
Un proyecto personal, una banda, una pyme, un colectivo, etc. (tiene que ser real).
* El sitio se diseña en Figma, se programa en HTML/CSS (JavaScript es opcional, según el nivel de cada estudiante) y se publica en GitHub Pages. El resultado tiene que ser un sitio con su propia URL que cualquier persona pueda abrir.
  
El día del examen cada estudiante deja su sitio publicado abierto en los computadores de la sala, donde se monta la muestra. Ese día tienen que estar entregados el link de GitHub Pages, el repositorio con la bitácora y el link de Figma.
