# bitácora solemne-02
un poco de dificultades decidiendo cómo jerarquizar las cajas y sus contenidos en el html, cuáles dejar a fuera y cuales adentro para facilitar el diseño en css.

Dentro del banner, hubo más complejidad con las cajas de contenido, decidiendo cómo ordenarlas en el código html, finalmente logramos un resultado satisfactorio con prueba y error modificando el .html y .css. Se hacen 2 cajas en fila, dentro de una de las cajas se crean sub-cajas para alinear los contenidos del lado derecho en una columna. 

Quisimos usar la misma fuente que usa la feria en sus publicaciones (Bungee), la encontramos en adobe fonts y con ayuda de un tutorial en youtube aprendimos a usar web projects de adobe fonts y efectivamente usar Bungee en nuestra página. 

para poner el patrón (un patrón que aparece en un documento informativo de la feria) que usamos en figma, aprendimos a usar otras propiedades de background en css con w3schools.com, para este caso del patrón usamos background-image, background-size y background-attachment.
