
# BAZR
### Siempre hay algo que encontrar.

## Descripción

BAZR es una plataforma digital dedicada a recopilar, documentar y compartir lugares y descubrimientos urbanos. A través de fotografías y registros de distintos usuarios, construye un archivo colectivo de espacios, objetos y expresiones visuales que forman parte de la vida cotidiana de una ciudad.

Su propósito es fomentar la observación y el descubrimiento, permitiendo que las personas encuentren lugares interesantes, conozcan nuevas perspectivas de su entorno y compartan aquello que consideran digno de ser recordado.

## Referentes

- [Cosmos](https://www.cosmos.so/) — Referente para la organización y recopilación visual de contenidos.
- [Are.na / MyMind](https://access.mymind.com/everything) — Referente para la disposición y presentación de contenidos en la página de inicio.
- [Awwwards](https://www.awwwards.com/) — Referente para la composición visual, distribución de imágenes y recursos gráficos.
