# Bitácora del Proyecto - MAREA
## Bitácora

### organización
* Nos pusimos de acuerdo con el tema y los colores. Buscamos referencias de tiendas de diseño y tonos que recordaran al mar y a la cerámica (azules, turquesas y tonos arena).
* Definimos qué secciones iba a tener la página (la portada, la galería de la colección, la parte del concepto, el taller y el pie de página).

### Creación del HTML
* Empezamos a armar el código base con HTML.
* Pusimos todas las etiquetas principales para ordenar el contenido en una sola página (*single page*).
* Agregamos todas las fotos que teníamos en la carpeta (`LOGO.png`, `foto grande.png`, `corriente.png`, etc.) y configuramos los botones con `target="_blank"` para que abran en otra pestaña por ahora.

### Diseñando con CSS
* Le dimos color y estilo a la página usando un archivo de CSS separado (`styles.css`).
* Usamos medidas en `rem` para mantener todo ordenado y bien proporcionado.
* Le pusimos efectos sencillos a los botones para que cambien de color al pasar el mouse o al hacer clic, tal como lo teníamos planeado desde el diseño.

---

## Herramientas que usamos
* **HTML5** y **CSS3** para armar la página.
* **Figma** para armar el diseño antes de pasarlo a código.
